Build notes: how the real version works
  1. Prompt to story. Send the prompt, grade band and text length to a language model with a social-story system prompt. Ask for JSON: {title, pages:[{text, type, setting, prop, emotion}]}. This mockup fakes that step with a template.
  2. Scene plan. Each page names a setting (classroom, hallway, outside, cafeteria, home), a prop and the character's feeling. Keep these to a fixed list so every style can draw them.
  3. Style renderer. A style is data: colors, outline weight, character shape, filters and motion. The same scene plan draws in every style, which is why switching is instant here.
  4. Optional image model. For richer art, send the scene plan plus the style's prompt words to an image model, and cache the result per page and style.
  5. Narration and export. Browser speech or a TTS service reads each page. Render frames to MP4 for video and to a PDF booklet for print.
