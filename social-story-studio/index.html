Build notes: how the real version works
  1. Prompt to story (live). Write story with Claude sends the situation, grade band, text length and chosen style to Claude, which returns structured JSON: {title, character, pages:[{text, type, setting, prop, emotion, scene}]}. On claude.ai it runs on your own Claude account; run locally, server.mjs calls the Claude API with your key. With neither, the built-in template is used.
  2. Scene plan. Each page names a setting (classroom, hallway, outside, cafeteria, home), a prop and the character's feeling. The lists are fixed so every style can draw them.
  3. Style renderer. A style is data: colors, outline weight, character shape, eyes, lighting, textures and motion. The same scene plan draws in every style, which is why switching is instant.
  4. Optional image model. Each page's image prompt joins the style's sample prompt with Claude's scene and character notes. Send it to an image model for richer art, and cache the result per page and style.
  5. Narration and export. Browser speech or a TTS service reads each page. Render frames to MP4 for video and to a PDF booklet for print.
